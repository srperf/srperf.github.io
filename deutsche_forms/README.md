# Deutsche Forms

A collection of HTTP pages to help you study German grammar through interactive tools and exercises.

## Overview

This project provides a series of web pages designed to help learners practice key aspects of German grammar. The current planned functionalities are described below. As we progress, more details will be added.

## Planned Pages / Functionalities

### 1. Pronouns by Case (Nominativ, Dativ, Genitiv, Akkusativ)

**Purpose:** Help learners identify and use German personal pronouns according to grammatical case.

**Features:**
- Reference table of personal pronouns (ich, du, er/sie/es, wir, ihr, sie/Sie) declined across all four cases:
  - Nominativ (subject)
  - Akkusativ (direct object)
  - Dativ (indirect object)
  - Genitiv (possession)
- Interactive lookup by pronoun, person, number, and case
- Example sentences showing each pronoun in context within its case

**Target:** Understand which pronoun form to use depending on the grammatical function in the sentence.

### 2. Position/Motion Verbs (legen, liegen, stehen, sitzen, stellen, setzen, etc.)

**Purpose:** Explain and practice German verbs whose meaning changes depending on whether the subject is moving (motion) or stationary (fixed position).

**Verbs covered (planned):**
- **legen / liegen** — to lay (motion) vs. to lie (fixed)
- **stellen / stehen** — to stand/place (motion) vs. to stand (fixed)
- **setzen / sitzen** — to seat/sit down (motion) vs. to sit (fixed)
- **hängen** — to hang (motion) vs. to hang (fixed)

**Features:**
- Definition of each verb pair (motion vs. static)
- Rules for choosing accusative (motion/direction) vs. dative (location/position)
- Example sentences contrasting the two uses
- Interactive quizzes to test when to use each form

**Target:** Master the distinction between movement (Akkusativ, *wohin?*) and location (Dativ, *wo?*).

### 3. Phrase Form Identification Exercises

**Purpose:** Train learners to recognize the type of phrase in a sentence and determine which adjective ending (adjektivendungen) to use.

**Features:**
- Sentences presented with an adjective position highlighted
- User identifies:
  - Phrase type (e.g., nominative, accusative, dative, genitive)
  - Article type preceding the adjective (definite, indefinite, zero article, possessive, etc.)
  - Gender and number of the noun
- System suggests or validates the correct adjective ending (strong, weak, mixed declension)
- Explanations for correct and incorrect answers

**Target:** Build intuition for German adjective declension based on phrase structure and article type.
